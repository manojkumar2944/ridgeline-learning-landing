# Ridgeline Learning — React starter

Prerequisites: Node.js 18+ and npm. Run `npm install`, `npm run dev`, then visit the printed localhost URL. Build with `npm run build`. Starter is intentionally limited to a functional entry point and brand header; implement the landing-page sections, accessible navigation and local registration behavior using the referenced designs and copy. Source artwork is in `public/images`. No external account/API needed for registration. Publish final implementation to GitHub and deploy to Vercel/Netlify, then provide genuine test logs.
